# The AI Surfer plugins

Plugins from The AI Surfer for Claude.

## Install the Clone Kit

In the Claude desktop app: **Customize → Plugins → + Add → Add marketplace**, paste
`zbabiarz/ai-surfer-plugins`, click **Add**, then install **The AI Surfer Clone Kit**.

The kit's guide, interview and voice run on The AI Surfer's server and need a Clone Kit
account. Start here: https://clonekit.theaisurfershowroom.com/start

Questions: hello@theaisurfer.com
